# 聊天命令速查（v2）

在 QQ 里直接发给机器人的命令（`/` 开头）。v2 新栈只有下表这些命令——白名单外用户发的一切命令静默忽略（白名单＝`vl.toml` 顶层 `whitelist` 与 `admins` 的并集，名单外的消息一律不响应）；标注「管理员」的仅 `vl.toml`（本项目的配置文件）里 `admins` 名单中的 QQ 可用。旧栈 AstrBot/插件命令（`/sid`、`/reset`、`/plugin`、`/memory` 等）在新栈不存在。两个术语：**黏性本地**＝云端故障后自动切到并稳住本地大脑的降级状态；**recall@1/@3**＝记忆检索结果第 1 条／前 3 条命中正确记忆的占比。

| 命令 | 谁能用 | 说明 |
|---|---|---|
| `/mood` | 白名单用户 | 查看她对你们关系的感觉（人设化描述，不含数值） |
| `/mood stats` | 管理员 | 查看好感度/心情数值详情 |
| `/mood reset` | 管理员 | 重置你这里的内心状态（重新开始积累） |
| `/diary` | 管理员 | 看今天（没有则最近一篇）的她的日记 |
| `/diary <YYYY-MM-DD>` | 管理员 | 看指定日期的日记，如 `/diary 2026-10-10` |
| `/eval help` | 管理员 | 评测用法说明 |
| `/eval memory [n]` | 管理员 | 记忆召回评测（默认 10 例，上限 50），输出 recall@1/@3 报告并存档控制台 |
| `/brain` | 管理员 | 查看大脑状态：当前模式（云端/黏性本地）、降级与鉴权连败计数、最近云端/本地 LLM 错误（含 HTTP code）、本地大脑进程状态；智能降级未启用（`fallback_enabled=false`）时提示按云端运行 |
| `/brain local` | 管理员 | 手动切到本地大脑保命（智能降级未启用时不可用） |
| `/brain cloud` | 管理员 | 切回云端大脑（下一条消息起生效；本地 llama-server 进程保留，可在控制台「引擎与人格」页用「只停本地引擎」停止） |

未注册的 `/` 命令一律静默忽略（她不会回复"我不认识这个命令"）。
