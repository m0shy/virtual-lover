## 备份清单语义（窗口内）

- `scripts/backup.bat` 继续覆盖 `local/astrbot_data`（冻结数据增量≈0，每次备份
  成本可忽略）与 `local/vl_data`（活数据）；milvus 卷不在备份清单（记忆数据已
  在 vl_data，卷本身随三件套停机不变）；
- **窗口关闭顺序纪律（§4-O14，不可倒置）**：
  1. 先删数据：`local/astrbot_data/`、`local/milvus/volumes/`（FROZEN 标记随之消失）；
  2. 再动备份脚本：从 `scripts/backup.bat` 与 `virtuallover/console/control.py`
     的备份清单摘除 astrbot_data 行；
  3. 摘除 compose legacy 组与 `.env` 镜像变量行；
  4. 本清单与 docs/回退.md 归档为历史文档。
- 若先动脚本后删数据，最后一次备份仍会打包已注定删除的旧栈数据——浪费且
  误导恢复判断，故顺序不可倒置。

## 防回归

- `local/astrbot_data/` 的任何写入（除本标记与备份工具的读取）都应被视为对
  回退能力的破坏：回退合并源一旦被 v2 改写，docs/回退.md 档 B 的整组回退即
  失去数据基础；
- 控制台/一键脚本不得提供任何"清理旧栈数据"的入口——窗口关闭只走手工 SOP。
